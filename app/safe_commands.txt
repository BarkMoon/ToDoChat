# ToDoChat 安全コマンド許可リスト
# ============================================================================
# ここに載っているコマンドは「実行（都度確認）」モードで自動的に許可されます
# （確認カードは表示されますが、クリック不要）。ファイル・ブランチ・リポジトリの
# 状態を変えない“読み取り専用”の操作だけを載せてください。
#
# 書き方:
#   ・1行1要素。前後の空白は無視されます。
#   ・空行と、# で始まる行はコメントとして無視されます。
#   ・[セクション名] で種類を区切ります。
#
# 迷ったら載せないでください。ここに無いコマンドは従来どおり手動確認になるだけで、
# 安全側に倒れます（＝誤って危険な操作が自動実行されることはありません）。
#
# 注意:
#   ・リダイレクト(> <)、コマンド置換($() ``)、サブシェル、`&`(バックグラウンド)、
#     改行を含むコマンドは、たとえ中身が安全に見えても自動許可されません
#     （この判定は safe_shell.py 側で行っています）。
#   ・`|` `&&` `||` `;` で連結された場合は、連結された全コマンドがこのリストに
#     載っているときだけ自動許可されます（例: `git log | head`）。
# ============================================================================


# [commands]

# 書き込みはリダイレクトが必要＝自動許可されない）。
# 他プログラムを実行できるもの(env, xargs, sudo, watch, time ...)や、

# [powershell] — 読み取り専用の PowerShell コマンドレット／エイリアス。
# 「実行（都度確認）」モードで PowerShell ツールを自動許可する対象です
# （判定は safe_shell.py の is_safe_powershell が行います）。
# 大文字小文字は区別しません（PowerShell 準拠。内部で小文字化して比較）。
#
# 載せてよいのは、単体でファイル・レジストリ・プロセス・サービス等の状態を
# 変えない“取得/表示/検査”系だけです。書き込み系(Out-File, Set-Content,
# Add-Content, Export-*, Tee-Object, New-Item, Remove-Item, Set-* ...)や、
# 他コード/メソッドを実行しうるもの(Invoke-Expression/iex, Invoke-Command,
# Start-Process, ForEach-Object/% ...)は載せないこと。
# ※ ForEach-Object は -MemberName でメソッド実行が可能なため除外
#   （例: `Get-Process | ForEach-Object Kill`）。
# ※ スクリプトブロック {} ・部分式 $() ・グルーピング () ・呼び出し演算子 & ・
#   リダイレクト(> <) を含むコマンドは、たとえ中身が安全に見えても自動許可
#   されません（safe_shell.py 側で弾いています）。
# ※ Where-Object は比較構文（`Where-Object Name -eq foo`）のみ安全に扱えます。
#   スクリプトブロック形 `Where-Object { ... }` は {} が禁止されるため自動許可外。
