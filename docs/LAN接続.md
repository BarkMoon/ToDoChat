# スマホ等からのLAN接続ガイド

同じネットワーク（自宅Wi-Fi など）にあるスマホや別PCのブラウザから ToDoChat に接続するための、**初回設定**と**解除方法**をまとめる。

> ⚠️ **セキュリティ注意**
> 現時点では認証機構が無いため、このポートに到達できる人は誰でも AI（CLI）を操作できる。
> **信頼できるネットワーク（自宅Wi-Fi / VPN）でのみ公開すること。** 公共Wi-Fiでは使わない。
> トークン認証は今後のステップ2で追加予定。

---

## 仕組みの概要

- ToDoChat 本体（`app/server.py`）は PC 上で HTTP サーバーとして動く。
- 通常は `127.0.0.1:8765`（**ループバック限定**＝そのPC自身からしか繋がらない）で待ち受ける。
- 環境変数 `TODOCHAT_HOST=0.0.0.0` を付けて起動すると**全ネットワークインターフェースで待ち受け**、同一ネットワークの端末から `http://<このPCのIP>:8765/` で接続できるようになる。
- この「LAN公開モード」で起動する専用ランチャーが **`start-lan.bat`**。

| ランチャー | 待受アドレス | 用途 |
|---|---|---|
| `start.bat` | `127.0.0.1`（ローカル限定） | PC 自身だけで使う（通常） |
| `start-lan.bat` | `0.0.0.0`（LAN公開） | スマホ等から接続する |

環境変数で個別に上書きも可能：
- `TODOCHAT_HOST` … 待受アドレス（既定 `127.0.0.1`）
- `TODOCHAT_PORT` … ポート番号（既定 `8765`）

---

## 初回設定手順

### ステップA：このPCのLAN IPアドレスを確認

コマンドプロンプトで `ipconfig` を実行し、`IPv4 アドレス` を確認する。
自宅ルーター配下なら通常 `192.168.x.x`（例：`192.168.1.25`）。

> 複数のIPv4が出る場合、`192.168.56.x`（VirtualBox）や `172.x.x.x`（WSL/Hyper-V）は仮想アダプタなので除外し、ルーターと同じ帯（例 `192.168.1.x`）のものを使う。
> `start-lan.bat` で起動すると、起動ログに接続すべきURLが自動表示される。

### ステップB：ファイアウォールでポート8765の受信を許可（初回のみ・管理者権限）

Windows ファイアウォールが外部からの接続をブロックするため、受信許可ルールを1つ追加する。

「スタート」→「cmd」を右クリック →**「管理者として実行」** し、次を実行：

```
netsh advfirewall firewall add rule name="ToDoChat" dir=in action=allow protocol=TCP localport=8765 profile=private
```

- `profile=private` … 「プライベート」に分類されたネットワーク（自宅Wi-Fi等）でのみ許可する安全側の設定。
- この設定は一度行えば残る（PC再起動後も有効）。

### ステップC：LAN公開モードで起動

- 既に起動中の ToDoChat があれば、**ウィンドウとサーバーのcmd窓を先にすべて閉じる**。
  （閉じないと新しい起動が「ポート8765は使用中」で弾かれ、古いループバック版が残ってしまう）
- **`start-lan.bat` をダブルクリック**して起動。
- 起動ログに次のような行が出れば成功：
  ```
  LAN     : 同一ネットワークのスマホ等からは http://192.168.1.25:8765/ で接続できます
  ```

### ステップD：スマホから接続

- スマホを **PCと同じWi-Fi** に接続。
- ブラウザで `http://<ステップAで確認したIP>:8765/`（例 `http://192.168.1.25:8765/`）を開く。

## 解除方法（LAN公開をやめて元に戻す）

### 1. ローカル限定の起動に戻す

- LAN公開が不要なときは `start-lan.bat` ではなく **通常の `start.bat` で起動する**だけでよい。
  （`start.bat` は `127.0.0.1` で待ち受けるので、そのPC以外からは繋がらない）

### 2. ファイアウォールの受信許可ルールを削除

受信許可そのものを取り消したい場合は、**管理者権限のcmd**で：

```
netsh advfirewall firewall delete rule name="ToDoChat"
```

削除できたか確認：

```
netsh advfirewall firewall show rule name="ToDoChat"
```
→「指定された条件に一致する規則はありません」と出れば削除完了。

## トラブルシューティング

**スマホから開けない場合、まず「サーバーがどのアドレスで待ち受けているか」を確認する：**

```
netstat -ano | findstr :8765
```

- `127.0.0.1:8765 ... LISTENING` … **ループバック限定**。`start-lan.bat` で起動できていない（＝古い `start.bat` 版が残っている等）。全ウィンドウを閉じてから `start-lan.bat` で起動し直す。
- `0.0.0.0:8765 ... LISTENING` … **LAN公開OK**。繋がらないならファイアウォール（ステップB）かネットワーク側を疑う。

| 症状 | 確認ポイント |
|---|---|
| `netstat` が `127.0.0.1` のまま | 古いサーバーが残っている。全部閉じて `start-lan.bat` で再起動 |
| `0.0.0.0` なのに繋がらない | ファイアウォールのルール（ステップB）を確認。`profile=private` かつ現在の接続が「プライベート ネットワーク」か |
| そもそもIPが違う | スマホとPCが**同じWi-Fi**か。ゲストWi-Fiやモバイル回線だと別ネットワークになる |
| ルーターの端末間通信が禁止 | 一部ルーターの「プライバシーセパレータ / AP隔離」機能をOFFにする |

## 外出先からも使いたい場合

このガイドは同一ネットワーク（自宅LAN）向け。外出先から使うには VPN（Tailscale 等）で PC とスマホを同一仮想ネットワークに入れる方式を予定（ロードマップのステップ4）。ポート開放でのインターネット直接公開は認証が無い現状では**行わないこと**。
